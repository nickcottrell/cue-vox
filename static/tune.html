Governed neural · the stack
1 · Personality → the character (a set of envelopes)
2 · Envelope → an energy band (chill / mid / peak): its sound + the min → max bounds it allows
3 · Register → a named mode inside the envelope (holds one or more voices + a policy)
4 · Voice → the Kokoro blend the register plays (the leaf)
5 · Situation + SSML → the script and words, filling the bounds
A human sets a legible limit at every layer; the model performs inside it. Nothing is a black box.
Envelopes · energy bands + their bounds
The card marked ● shaping is the envelope picked in the Envelope dropdown up top. Pick one there, or click any card here, to choose which envelope you shape. They are one selection.
Each envelope is a timbre (how the band sounds) plus a prosody envelope (how it reads the same markup). Scalars are single values; ranges read as min → max (min = gentlest, max = boldest; a wider range = a more expressive band). Every knob names its own scale, so a value reads as a place (natural, punched) not just a number. Its registers & voices live on the Voices tab.
Saving writes voices.json, so it survives boot.
Voices · the neural blend each envelope plays
A Voice is the leaf: the Kokoro blend an envelope's register plays. Set the blend for each envelope (chill / mid / peak) here. Each is a weighted mix of the base Kokoro voices, so an envelope can literally sound like a different person. Envelopes are added/removed on the Envelope tab; here you set what each one sounds like.
The pipeline: edit an envelope's voice mix → Save & rebuild (regenerates the blend and hot-swaps the live engine) → go to the Tuner, pick that envelope, and Play to hear it.
