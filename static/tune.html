1 · Shape the words
Edit text + markup above, then iterate: Regenerate augments the markup (words unchanged), Translate infers markup from plain typing, Parse shows how it renders.
2 · Hear it
Synthesize the text with the current dials. This is the clay: tweak dials or markup, hear, repeat.
3 · Package (the loop)
Export crystallizes the whole feel (text + dials) into a portable, versioned SVG. Import reads one back in. Tune → Export → Import → tune.
4 · Deploy
Apply to live pushes this voice to the running conversation now. Deploy writes it to maestro as the voice cue-vox boots with.
The instrument
The dials above PLAY the register ladder. To change what the ladder IS (the voice blend in each slot), open the Register Ladder tab.
Registers · per-register prosody rules
Each register is a timbre PLUS its own reading of the SAME markup. break stretches every <break/> and <beat/>, emphasis shapes how hard <emphasis>/CAPS push, rate multiplies speed, lift is the question rise. speed/bright/gain are the timbre knobs (the only difference between registers on a stock voice with no neural blend). Saving writes voices.json, so it survives boot.
Register ladder · the instrument
The dials in the Tuner PLAY this ladder. Here you set what it IS: each slot (0 breathy → 4 dramatic) is a blend of base voices. Fill the slots, rebuild, and the live engine hot-swaps.
Slots
Save writes maestro/config/voice/blend.json. Rebuild regenerates register-voices.bin and hot-swaps the running engine, so the next spoken line uses the new blend. Audition slots with the register dial in the Tuner.
